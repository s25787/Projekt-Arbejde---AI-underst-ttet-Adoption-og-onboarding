# Prøv IdrætsID

1. Til en person på computer: Send **idraetsid-demo.html** fra release-mappen. Kun denne ene fil er nødvendig.
2. Gem filen og åbn den med Chrome, Edge, Firefox eller Safari. Eventuelt højreklik → Åbn med → browser. Den virker uden internet og installation. Brug fiktive oplysninger og demokoden **1234**.
3. Til mobil: Upload hele indholdet af **dist/** til simpel statisk HTTPS-hosting. Bevar mapperne og deres relative stier. Åbn adressen på mobilen. Der er ingen backend. Projektet er ikke publiceret.
4. På iPhone: Safari → Del → Føj til hjemmeskærm → Åbn som webapp, når denne mulighed vises. På understøttede andre browsere kan appen vise browserens installationsprompt. Mobilinstallation kræver HTTPS-udgaven; HTML-filen er en separat delingsmulighed. Indlæs hele webappen én gang online, før offlinebrug.
5. Åbn **Demo** øverst og vælg **Nulstil demo**. Kun denne prototypes lagrede profil ryddes. Start som ny eller eksisterende bruger, eller prøv login igen samme sted.

Alle identitets-, Face ID-, PIN- og loginhandlinger er simulationer. Der sendes ikke oplysninger til DIF, MitID eller Roskilde IF.
